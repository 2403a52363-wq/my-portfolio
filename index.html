About

I'm a third-year B.Tech student in Computer Science and Engineering (AI & ML) at SR University, Warangal.

My work so far sits where machine learning meets healthcare: a deep-learning system that explains its chest X-ray readings in 3D, and an IoT platform that lets families and doctors monitor elderly patients remotely over long-range LoRa radio.

I like projects that go all the way through: the model, the interface a clinician would actually use, and the written paper that explains it.

Projects

LungAI

Chest X-ray diagnosis with a 3D explainability layer

A deep-learning system that reads chest X-rays and then shows its reasoning. Grad-CAM attention maps are projected onto an interactive 3D lung model, so a reader can see which region of the lung drove each prediction.

It ships as a full clinical-workstation web app, and the work is written up as an IEEE-format paper with 26 references. I led this capstone with one teammate.

0.8318macro-averaged test AUROC, patient-wise split, 22,424 test images

AyuLink

Smart Health. Zero Boundaries.

A remote patient-monitoring system for rural elder care. Sensors on the patient send readings over LoRa to a gateway, and AI-assisted dashboards and alerts help families and doctors respond early.

Built for SR University's Pragathi 2.0 national-level project expo, with a live web dashboard.
